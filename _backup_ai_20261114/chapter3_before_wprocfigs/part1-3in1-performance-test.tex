\subsection{样机性能测试}
\label{subsec:3in1_performance_test}

为检验“三合一”脉冲式冲刮刷集成式井筒清洁工具（以下简称“三合一”工具）各功能模块的实际工作性能，在厂内试验台与东营试验基地分别对毛刷刮管器、脉冲器、液压刮管器及旋转喷头开展了单独测试。其中，毛刷刮管器重点考核装配完成后工具的通过性以及毛刷与管壁的接触状态；脉冲器重点考核起振排量、起振压力与振动频率；液压刮管器重点考核投球激活、刮刀张开行程及刮刀回收性能；旋转喷头重点考核不同排量下喷头的旋转起动特性。试验样机的主要参数见表\ref{tab:3in1_test_params}～表\ref{tab:3in1_brush_params}。

\subsubsection{试验结论与改进措施}

综合各模块的试验结果，可得如下结论：

\begin{itemize}
	\item 毛刷刮管器装配后可通过$\phi$114\,mm试验管段并往复活动，毛刷与管壁保持接触，满足入井刮刷对通过性的要求；
	\item 脉冲器在300\,L/min、泵压波动$0\sim4$\,MPa条件下可正常起振，振动频率为$15\sim20$\,Hz；但当泵压大于8\,MPa时弹簧压并不回弹，需通过更换大口径喷嘴、加大弹簧预压力予以改进；
	\item 液压刮管器在15\,MPa时未动作、17\,MPa时刮刀张开，张开行程约8\,mm；停泵后刮刀不能自行回收，需拆卸管线后才能回位，反映剪钉剪切压力与刮刀回位机构仍需优化；
	\item 旋转喷头单独试验时，在$350\sim400$\,L/min、2.2\,MPa条件下即可旋转；接入刮刀与脉冲器后需在泵压不低于3\,MPa时才转动；东营基地试验中因上部压耗过大未能转动，需在整机联调中重新匹配排量与压耗。
\end{itemize}

针对试验中暴露的问题，后续将从喷嘴通径、弹簧预压力、剪钉配置与球座结构以及喷头压耗匹配等方面对工具进行改进，并在整机联调中复测验证。

\subsection{适用井况}

本工具适用于直井、斜井与水平井；可处理套管内壁的水泥、砂砾、钡锶垢、残留弹片、金属毛刺、石蜡、
硬石蜡、油污、铁屑、锈垢、泥块等附着物；适用于新井射孔前通井、修井清洁维护等场景，适配洗井、冲砂、
刮壁、酸化等工艺。

本章工具为 5-1/2\inch 系列（组装外径 $105\sim114$\,mm、毛刷最大外径 130\,mm），适用于 5-1/2\inch
套管（内径约 $115.5\sim125.7$\,mm）及内径相当的尾管段，不得用于 9-5/8\inch 主井眼；9-5/8\inch 主
井眼的清洁由第 1$\sim$4 章工具完成。

\subsection{管柱组合}

组合前需先确认井况，明确套管规格、井深及污染物类型，同时校验各工具连接扣型、外观无损伤且活动部件
连接稳固。管柱自上而下依次为：上部钻柱、毛刷刮管器、液压刮管器、脉冲器、旋转喷头；旋转喷头即为管串
最前端（最下端），其下方不再连接任何工具，强磁打捞器可选用并置于清洁段后方。

其中，旋转喷头负责旋转喷射冲砂、洗井；脉冲器产生低频脉冲冲击波疏松顽固垢层；液压刮管器机械刮削水泥、
残留弹片等硬质附着物；毛刷刮管器精细刷洗残留软垢、石蜡；上部钻柱传递提拉与旋转力；强磁打捞器可吸附
未被循环液返出的磁性碎屑。通井、洗井作为独立工序，另用通井规（通井钻头$+$扶正器）完成，不串入本组合
前端。

可根据作业需求灵活调整：仅需冲砂洗井时，保留旋转喷头、脉冲器与上部钻柱即可；仅需刮管作业时，可采用
液压刮管器、毛刷刮管器与上部钻柱；若需打捞磁性碎屑，在标准组合上方增强磁打捞器。

\subsection{施工工艺步骤}

组合管柱的施工按“入井—到底冲砂—投球开刀—自上而下刮刷—过密封筒—循环起钻”六步组织实施，各步作业
参数与判据如下。

\begin{enumerate}[label=(\arabic*),leftmargin=2em,itemsep=2pt]
	\item \textbf{入井}：管柱自上而下按上部钻柱、毛刷刮管器、液压刮管器、脉冲器、旋转喷头的顺序连接，
	旋转喷头即管串最前端。此时未投球，液缸不动作，刮刀在复位弹簧作用下收于刀槽内，工具最大外径小于
	套管内径，可顺利通过 4.75\inch 密封筒等缩径段。下放速度控制在较低水平，遇阻时缓慢转动管柱数圈后
	再下放，不得硬压；每下入数根立柱记录一次悬重，作为后续判断刮削阻力的基准。
	\item \textbf{到底冲砂}：管柱下至处理井段底部以上 $3\sim5$\,m 处开泵，排量由小到大阶梯提升。旋转
	喷头的工作排量为 $100\sim300$\,L/min、脉冲器为 $100\sim500$\,L/min，同趟作业取两者交集。脉冲器的
	周向出水孔在压力脉动中反复开合，对沉砂床和孔眼口部形成交变水力冲击，冲散沉砂、剥松垢层；旋转喷头
	依靠切向喷嘴的反作用力矩带动整串工具缓慢自转，启动转速低于 0.6\,r/min，使脉冲射流在圆周上均匀
	扫过，避免只冲出一条沟槽。冲砂阶段以脉冲冲刷为主，此时刮刀尚未张开，清洁主要靠水力和自转完成。
	\item \textbf{投球开刀}：冲至设计深度后上提管柱至上部筛管顶端，从井口投入钢球，球落座后管内憋压。
	球座打通所需泵压为该工具打开压力与静液柱压力之差（绝对打开压力 $=$ 静液柱压力 $+$ 泵压）；泵压
	先升后降即为刮刀张开的直接标志，刀片随之张开并贴住套管内壁。开刀后先小幅度上提、下放，观察悬重与
	泵压变化，确认刀片贴壁、工具无遇卡，再转入正式刮削。
	\item \textbf{自上而下刮刷}：上提过程中刀片对垢层产生剪切作用，清除水泥环、硬垢、蜡质与毛刺；上方的
	毛刷同步刷洗，把刮松的残渣从孔眼口部剥离，由循环液携带出井。刮刷时保持循环畅通，指重表无明显显示
	（下放悬重不降、上提悬重不升）即该段已刮净。每上提 $10\sim20$\,m 可停泵循环一次，把本段垢屑带出
	井口，防止停泵后回落沉积。
	\item \textbf{过密封筒}：4.75\inch 密封筒是完井密封面，一旦划伤，封隔器难以坐封。上提至密封筒以下
	$2\sim3$\,m 处停泵卸压，刀片在复位弹簧作用下收回，确认收刀后缓慢通过。通过时若悬重明显增大，说明
	刀片未完全收回，应重新卸压并活动管柱，必要时投入复位钢球，不得带刀硬过。这一段工具处于空过状态，
	不刮削、不带压，目的只是完整通过。
	\item \textbf{循环起钻}：刮刷至设计井段后保持大排量循环洗井，直至返出液无明显砂粒与垢屑。停泵泄压，
	平稳低速起钻，严禁猛提猛刹。工具出井后检查刀片磨损与崩刃、毛刷断丝、喷嘴冲蚀、脉冲器密封及球座
	动作，损坏件更换，完好件清洗涂油后入库。
\end{enumerate}

\subsection{注意事项}

\begin{itemize}
	\item 脉冲器与管柱的连接扣必须拧紧，公扣端朝下；下入过程中如遇阻，应慢慢旋转几圈后再下放；
	单次连续振动不得超过 10\,min，累计振动每满 1\,h 应停振 10\,min 散热。
	\item 液压刮管器与管柱的连接扣必须拧紧，下井过程中如遇阻应慢慢旋转几圈后再下放，刮削过程中必须
	始终保持循环畅通；起钻前先停泵泄压并确认刮刀收回。
	\item 一趟管柱内同时使用多种液压启动工具时，应预先确定投球顺序与憋压值，避免先投球激活的工具
	影响后续工序。
\end{itemize}
